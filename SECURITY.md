# Security

## Reporting a vulnerability

Email **security@wallras.com** with what you found and how to reproduce it. Please don't open a public issue for security problems.

We aim to acknowledge reports within 3 working days and to keep you updated until the issue is fixed. Please give us a reasonable time to fix it before telling others. We won't take legal action against good-faith research that avoids privacy violations, data destruction and service disruption.

This repository holds the Wallras Python SDK and MCP server. Reports about the Wallras engine, the website or the license server are welcome at the same address.

How Wallras is secured and tested: https://wallras.com/security
